
# Grade Reporter & Bug Hunt

PLP Python Week 3 Assignment

## Files

- `grade_reporter.py` - Calculates learner grades, pass and fail counts, and average scores.
- `bug_hunt.py` - Fixes three bugs in a Python while loop and calculates the sum of numbers 1 to 5.

## Bug Hunt Reflection

The hardest bug to find was the while loop condition excluding the number 5. The program did not produce an error message, but the answer was 10 instead of the expected 15. I knew something was wrong by comparing the output with the correct sum of 1, 2, 3, 4, and 5.
